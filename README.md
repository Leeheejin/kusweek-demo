의류 탐색, 이미지 기반 디자인 구성, 제작 상담과 업체 검토를 연결하는 정적 웹 데모입니다.

Hanju의 공개 페이지에서 확인한 정보 구조와 견적·상담 흐름을 의류 도메인으로 재구성했습니다. 원 사이트의 문구, 납품 실적, 가격이나 연락처를 전용하지 않았습니다.

## 실행

현재 폴더를 정적 HTTP 서버로 열면 됩니다. 별도의 빌드, API 키, 로그인은 필요하지 않습니다. GitHub Pages 배포를 지원하도록 상대 경로와 해시 라우팅을 사용합니다.

## 데모 범위

세 가지 의류 디자인, 컬러와 지원 핏의 사진 전환, 필드 재킷의 네 가지 각도, 문구 디테일 미리보기, 수량별 예시 금액, 디자인 보관함, 참고 파일 첨부, 제작 요청서, 고객·업체 대화, 제작 단계 변경과 PDF 자료를 제공합니다.

요청·연락처·채팅·첨부는 **현재 브라우저에만** 저장됩니다. 같은 브라우저의 탭 사이에서 동기화되지만 실제 업체나 다른 기기로 전송되지 않습니다. 자동응답은 명시적으로 켜는 규칙 기반 시연이며 실제 담당자나 AI가 아닙니다. 금액과 제작 사례는 예시입니다.

실제 CAD 자동 생성, 제조 실행, 결제와 업체 알림은 연결되어 있지 않습니다. 운영 시 필요한 서버·권한·파일 저장소·알림·AI/CAD 검토 연동은 시연 가이드에 정리했습니다.

## 자료

`downloads/`에는 공개 데모용으로 새로 작성한 카탈로그, 사이즈 가이드, 제작 브리프만 포함합니다. 내부 진단 보고서와 원본 기업 PDF는 포함하지 않았습니다. 제품 이미지는 이 프로젝트에서 준비한 시각 샘플이며 실제 판매 제품이나 실적의 사진이 아닙니다. Pretendard 폰트 라이선스는 `PRETENDARD-LICENSE.txt`를 참고하세요.

기존 버전의 HTML은 비교와 복구를 위해 남겨두었습니다. 현재 홈페이지는 `index.html`, `app.js`, `style.css` 및 관련 모듈입니다.
