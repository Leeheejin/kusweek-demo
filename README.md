# KUSWEEK — 보는 순간, 만드는 일이 시작된다.

고객의 가상샘플 경험에서 제안형 수주, 내부 설계·제작·콘텐츠까지 연결하는 AX 비전 웹사이트입니다.

## 여섯 장면

1. 가상샘플 발견: 소재와 형태를 먼저 살펴보는 경험.
2. 요구사항: 디자인·핏·컬러·소재·사용 장면을 구체화.
3. 제안형 수주: AI가 고객 요청을 구조화하고, 영업·기획이 대안을 제안하며 합의 브리프를 작성.
4. AI·CAD: 기존 패턴 자산과 브리프를 바탕으로 변경 초안을 제안하고 전문가가 검토.
5. 제작·승인: 소재·원가·수량·일정 검토, 실물 샘플, 수정·승인, 생산·검품 연결.
6. 다음 제안: 설계·제작 기록을 룩북·상세페이지·B2B 제안 및 반복 운영에 재사용.

핏·컬러 선택은 브리프와 CAD 장면에 연결됩니다. 선택은 페이지 메모리에만 존재하며 외부로 전송하지 않습니다. 현재 구현은 미래 경험을 설명하는 시각적 콘셉트입니다. 실제 주문 접수, CAD 자동 생성, 생산 시스템 호출은 하지 않습니다. 기존 3D 모델은 포함하지 않습니다.

## 실행

저장소의 `index.html`은 이미지·폰트·CSS·JavaScript를 포함한 단일 파일로, 브라우저에서 바로 실행합니다. GitHub Pages는 `main` 브랜치 루트에서 게시합니다.

소스 ZIP에서는 `preview.html`을 정적 서버로 실행하면 됩니다. `index.html`은 패턴 SVG 삽입 전 편집용 템플릿이며, `pattern.svg`가 별도 제공됩니다. 별도 빌드 결과물은 저장소 루트 `index.html`입니다.
